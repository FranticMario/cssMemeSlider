In diesem Projekt wurde ein animiertes Karussell erstellt, um beliebte Memes im GIF-Format nur mit HTML und CSS anzuzeigen. Das Karussell ermöglicht es dem Benutzer, mithilfe von interaktiven Radiobuttons, die in die Navigation integriert sind, zwischen verschiedenen Memes zu wechseln.
